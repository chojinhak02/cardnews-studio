# 경주역신도시부동산 카드뉴스 스튜디오

직접 확인한 정보를 바탕으로 인스타그램 세로형 카드뉴스 6장을 만드는 로컬 웹사이트입니다. 블로그 사이트와 별개의 프로젝트입니다.

## 실행

`dist/index.html`을 브라우저에서 엽니다. 별도 설치나 서버가 필요하지 않습니다.

GitHub Pages는 `main` 브랜치에 변경사항이 올라오면 `.github/workflows/pages.yml`을 통해 `dist` 폴더를 다시 게시합니다.

## 사용

1. 주제, 대상 독자, 핵심 정보, 전달할 문장, 마무리 안내를 입력합니다. **경주역신도시 예시로 채우기**를 눌러 전체 입력 예시를 볼 수 있습니다.
2. **카드뉴스 초안 만들기**를 누른 뒤 각 카드의 문구와 디자인을 편집합니다.
3. 게시 전 점검을 확인합니다. 긴 문구로 PNG가 잘릴 수 있으면 해당 카드의 내보내기가 중단됩니다.
4. **보관함에 저장**을 누르면 현재 작업이 해당 브라우저에만 저장됩니다. **현재 카드 PNG** 또는 **전체 PNG 다운로드**는 1080×1350 이미지를 받습니다.

입력과 편집 내용은 자동 저장되지 않습니다. **초기화**는 현재 작업만 비우며 보관함 항목은 유지합니다. 카드뉴스 문구는 입력 내용을 정리한 초안이며, 가격·일정·정책 등 변동 가능한 사실은 게시 전에 확인해야 합니다.

첫 버전의 카드뉴스 6장이 기본으로 표시됩니다. 같은 브라우저에 첫 버전의 작업이 남아 있으면 그 카드 문구를 우선 표시합니다. 이 과정에서 이전 저장값을 삭제하거나 새로 저장하지 않습니다. 이후 내용을 유지하려면 **보관함에 저장**을 직접 누르세요.
